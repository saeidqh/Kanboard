# Modern Theme برای Kanboard

تم مدرن و حرفه‌ای با تمرکز روی:

- **نوبار کاملاً مجزا** با فاصله از لبه‌ها و سایه بالشتکی
- **رنگ آبی خوش‌رنگ** (گرادیان آبی حرفه‌ای)
- **گوشه‌های گرد** در همه جا
- **تفکیک واضح منوها** — هر آیتم منو به صورت دکمهٔ جدا با پس‌زمینه نیمه‌شفاف

## نصب

1. پوشه `ModernTheme` را داخل مسیر `plugins/` کان‌بورد کپی کنید:

```bash
cp -r ModernTheme /path/to/kanboard/plugins/
```

2. از پنل ادمین → Plugins پلاگین را فعال کنید.

3. کش مرورگر را پاک کنید (Ctrl+F5) و صفحه را رفرش کنید.

## ساختار فایل‌ها

```
ModernTheme/
├── Plugin.php
├── README.md
└── Assets/
    └── css/
        ├── variables.css   ← توکن‌های طراحی (رنگ، فاصله، سایه، radius)
        ├── base.css        ← استایل‌های پایه و تایپوگرافی
        ├── header.css      ← نوبار اصلی (مهم‌ترین فایل برای ظاهر هدر)
        ├── board.css       ← چیدمان بورد و ستون‌ها
        └── cards.css       ← کارت‌های تسک
```

## سفارشی‌سازی رنگ

برای تغییر رنگ اصلی آبی، فایل `variables.css` را باز کنید و مقادیر `--mt-blue-*` و `--mt-header-bg` را تغییر دهید.

مثال برای آبی تیره‌تر:

```css
--mt-header-bg: linear-gradient(135deg, #1e40af 0%, #1e3a8a 100%);
--mt-header-bg-solid: #1e40af;
```
